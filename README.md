## 它能做什么

| | |
|---|---|
| 🔒 **锁机** | 锁上之后，只有白名单里的应用能打开。想开别的？会被弹回锁机页 |
| ⏰ **定时锁机** | 比如「每天 23:00 锁 8 小时」，到点自动锁、到点自动解，不用你管 |
| 🍅 **番茄钟** | 专注 25 分钟 → 休息 5 分钟 → 再专注…… 专注时段自动锁机，休息时段自动解锁 |
| 📅 **法定节假日** | 定时规则可以选「跳过节假日」，春节国庆不会误锁 |
| 📝 **白名单分组** | 把应用分组成「学习」「工作」等，不同时段用不同的一组 |
| 🔑 **解锁 PIN** | 不想中途反悔？设个 PIN，解锁得输密码 |

## 第一次使用：照这个顺序做

### 第一步：把权限配齐

打开 App，**点右上角的「加固权限」**，里面列了 7 项权限，挨个点开按提示授权就行。

**这 7 项缺任何一项，锁机都会漏风**（看起来在跑，其实能被绕过去，而且不报错）。所以别嫌麻烦，一次配齐。

其中最重要的是**无障碍服务** —— 它是锁机的地基，一定要开。

### 第二步：挑白名单

点底部「**白名单**」，把锁机期间**允许使用**的应用勾上。

> 💡 **建议至少留下：电话、短信、闹钟、输入法。**
> 这样锁机期间还能打电话、看时间、打字。

### 第三步：设个解锁 PIN（可选）

首页 → 设置 → **解锁 PIN**。

不设也能用，但锁定期间点「解除锁定」就能直接解开，等于没锁。

> 忘了 PIN 怎么办？见下面的[常见问题](#常见问题)。

### 第四步：开始用

回到首页，两种玩法：

- **⏳ 简单锁机** —— 点一下，选个任务（比如「锁机 1 小时」），立刻开始
- **🍅 番茄钟** —— 点一下，选个番茄钟任务，按专注/休息的节奏自动轮转

想每天固定时间自动锁？去「**定时**」页新建一条规则。

## 小米 / 红米用户必看

MIUI / HyperOS 对后台管控很严，**不做下面这两项，锁机会用不了**。

### ⭐ 后台弹出界面（最关键）

**不做这一项，锁机页拉不起来** —— 症状是「无障碍开着、定时也到点了，但屏幕没被锁上」。

> 设置 → 应用设置 → 应用管理 → **等闲** → 权限管理 → 其他权限 → **后台弹出界面** → 允许

### 省电策略改成「无限制」

不改的话，息屏后进程会被系统冻结，**定时锁机不触发**。

> 设置 → 应用设置 → 应用管理 → **等闲** → 省电策略 → **无限制**

### 还有两个建议开

| 设置 | 在哪 | 为什么 |
|---|---|---|
| **自启动** | 应用管理 → 等闲 → 自启动 | 重启手机后定时闹钟才能恢复 |
| **锁定后台任务** | 最近任务 → 等闲卡片 → 下拉 → 点小锁 | 防止「一键清理」把它杀掉 |

> 💡 **这些菜单在不同系统版本里名字/位置会变。最快的方法：在「设置」顶部搜索框直接搜关键词**，比如搜 `后台弹出界面`、`自启动`、`省电策略`。

## 四个页面分别是干嘛的

### 🏠 首页

看当前状态，也是开始锁机的地方。

- 上面一张卡：现在锁没锁、下次什么时候锁
- 下面两张卡：**简单锁机** / **番茄钟**。点开选个任务就开始
- 右上角「加固权限」：权限体检表 + 出问题时用的诊断日志

### ☰ 白名单

决定锁机期间**哪些应用能用**。

- **全局白名单**：永远放行，不管有没有锁
- **分组**：一套应用。什么时候用哪一组，由定时规则决定

### ⏰ 定时

让手机自动锁。

每条规则 = **什么时候** + **锁什么** + **哪些天**。

- 「锁什么」有两种：自己设一个时长，或者选一个现成的「任务」
- 还能选「跳过法定节假日」，春节国庆不误锁

### ⚙️ 设置

- **锁机选项**：要不要允许用 PIN 提前解锁
- **解锁 PIN**：设密码，可以一键随机生成 4 位
- **锁机页壁纸**：纯色，或者换成你自己的图片（会自动加模糊）
- **任务**：管理「简单锁机」和「番茄钟」的预设

## 常见问题

### 锁上了，但我现在有急事 / 忘了 PIN

**有 PIN**：锁机页右滑到最后一页，点「解除锁定」，输 PIN。

**忘了 PIN**：只能走系统设置 ——
> 设置 → 更多设置 → 无障碍 → **等闲 锁机服务** → 关掉

关掉之后锁机立刻失效，你就能正常用手机了。

> 这也是为什么这个 App 不需要 root：**它拦得住应用，拦不住你去关它的权限。**
> 它的作用是「给你一个冷静期」，不是「把你锁死」。

### 锁机不管用，该拦的还能打开

按顺序检查：

1. **无障碍服务是不是被系统关掉了** —— 回 App 首页看有没有红色的警告卡片
   （装完新版本 APK 后，系统经常会自动关掉无障碍服务，需要重新开一次）
2. **小米/红米**：确认[「后台弹出界面」](#-后台弹出界面最关键)开着
3. **省电策略**是不是被系统重置成「智能省电」了 —— 改回「无限制」

### 会不会影响打电话、报警？

**不会。** 电话、短信、拨号盘永远放行，输入法和系统界面也永远放行。

### 会不会偷偷联网 / 上传我的数据？

**不会。** App 里没有任何联网代码，也没有申请网络权限。所有配置都只存在你自己手机里。

### 我想看一下它到底在干嘛

首页右上角「加固权限」页最下面有**诊断日志**，记录了每一个窗口切换事件。点「复制全部」就能发出来求助。

### 从旧版本升级后，配置没了？

如果你用的是 **2.1.0 之前**的版本（那时 App 还叫 SelfLock、包名是 `com.selflock`），
2.1.0 换了新包名，系统会把它当成一个**全新的 App**：

- 旧版本不会自动卸载，需要你手动删掉
- 白名单、定时规则、分组、任务都要**重配一次**

## 卸载

**正常情况**：长按图标 → 卸载。（如果开了「设备管理员」，先在 App 的设置里关掉）

**卸不掉的话**（比如正锁着、或者被设备管理员挡住）：

> 设置 → 更多设置 → 无障碍 → **等闲 锁机服务** → 关掉

关掉之后锁机立刻失效，就能正常卸载了。
